# Web Search 使用指南

当用户的问题需要最新信息（新闻、版本号、价格）时，调用 web_search 工具。

## 步骤

1. 提炼 2-3 个关键词组成查询，避免整句提问；
2. 查看返回的来源列表，优先选择官方站点与高权威来源；
3. 回答时引用具体来源，标明信息获取时间；
4. 搜索结果与用户问题无关时，换一组关键词重试。

## 注意事项

- 模型自身知识有截止日期，凡是「最新」「当前」类问题一律先搜索；
- 引用来源 URL 时使用返回结果中的原始链接。
